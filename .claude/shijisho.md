# 指示書

完了した項目にはチェックを付けてください。矛盾点があれば必ず質問してから進めてください。

## 概要

このサイトでは、駅名標を「手動で生成」または「路線を作って生成」することができます。すべての作業はローカルで完結し、アカウント連携機能などは実装しません。生成したSQLiteファイルは、ユーザーが必要に応じてダウンロードすることができます。

## 実装13：路線図の乗り換え表示

現在の路線図モードにおける乗り換え案内の出力は、かなりわかりにくいものになっています。これを以下の指示に沿って作り変えてください。

1. [x] 現在の路線乗り換え表示表記（駅名の横に路線の色と白文字）は廃止してください。
2. [x] 乗り換え路線は、初期状態では一つも選択しないようにしてください。
3. [x] 駅の乗換情報だけではなく、乗り換え先路線名を表示するかどうか（表示しない場合は路線アイコンのみ）も選択制にしてください。
4. [x] 路線アイコンが存在しない場合（＝路線名略称が未定義の場合）は、路線アイコンの代わりに文字なしで四角形（角丸なし）のみ表示してください。
5. [x] 縦方向モードの場合は、以下のように実装してください。
   1. [x] 駅名の側が右の場合、駅名（primaryとsecondaryのいずれか長い方）の左上を基準として、路線バッジ（駅番号バッジではない）を表示し、その右に路線名を書く。最大3行となるようにし、3行を超える場合は3行のうち最も長いものの右端を基準として右に積み同様に繰り返す
   2. [x] 駅名の側が左の場合、左が路線バッジで右が路線名となること以外はすべて左右を反転して同様に実装する。
6. [x] 横方向モードの場合は、以下のように実装してください。
   1. [x] 駅名スタイルが上（縦書き）の場合、駅名（primaryとsecondaryのいずれか長い方）の左上を基準として、路線バッジ（駅番号バッジではない）を表示し、その上に縦書きで路線名を書く。最大3行となるようにし、3行を超える場合は3行のうち最も長いものの上端を基準として上に積み同様に繰り返す
   2. [x] 駅名スタイルが下（縦書き）の場合、すべて上下を反転して同様に実装する。

## 実装18：JR東日本の分岐

1. [ ] JR東日本風に限定して、2路線分岐を実装してください。
   1. [ ] .claude\noshare_sample\jreast_bunki_without_number.png および .claude\noshare_sample\jreast_bunki.png を参考にして、JR東日本の左右においてレイアウトを分岐させられるようにしてください。
   2. [ ] 写真にある通り、分岐させる場合は進行方向であっても次の駅名が小さくなります。この点も気をつけてください。
   3. [ ] 分岐先の矢印は、会社カラーを変更することがあります。現在のデータベーススキームが他社路線への直通をサポートしているかどうかを検査し、なければまずマイグレーションを実装してください。
2. [ ] JR東日本風に限定して、3路線分岐を実装してください。
   1. [ ] .claude\noshare_sample\jreast_fork.png を参考にして、JR東日本の左右においてレイアウトを分岐させられるようにしてください。
   2. [ ] 写真にある通り、分岐させる場合は進行方向であっても次の駅名が小さくなります。この点も気をつけてください。
   3. [ ] 3路線分岐をした場合、現在の縦横比では収めることができません。その分縦に伸ばす仕様としてください。

## 実装19：JR東海風駅名標

1. [ ] .claude\noshare_sample\jrtoukai.png を参考にして、JR東海風デザインの駅名標が作成できるようにしてください。特に新しく作る必要のあるフィールドはないと思います。ただし、左上のJR東海のロゴは位置のみ記憶して空白としてください。
   1. [ ] 前提として、JR東海風の駅番号スタイルを追加してください。レイアウトは .claude\noshare_sample\jrtoukai_number.png を参考にしてください。数字が10未満の場合はゼロパディングを行ってください。
   2. [ ] 新しくフォントを導入する必要があるかもしれません。JR東海風の駅名標にふさわしいフォントを提案してください。
